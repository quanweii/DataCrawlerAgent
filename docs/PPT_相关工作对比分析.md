## 第2页：研究背景与问题

### 我们要解决什么问题？

**核心问题**

学术论文是一种天然的**多模态属性图**数据：
- 节点 = 论文
- 边 = 引用关系
- 属性 = 文本 + 图片 + 公式 + 图表

**现有数据集的困境**

| 困境 | 描述 |
|------|------|
| **困境一** | 有学术论文图数据集，但没有多模态属性<br>(OGB, Cora, CiteSeer → 只有文本特征) |
| **困境二** | 有多模态属性图数据集，但不是学术论文领域<br>(MAGB, MM-GRAPH → 社交/电商/电影领域) |
| **困境三** | 缺乏自动化、标准化的数据采集工具<br>(数据质量参差不齐，难以复现) |

**我们的定位**

> 首个专注于**学术论文领域**的**多模态属性图**Benchmark

## 第4页：对比对象一 - OGB

### 对比对象一：OGB (Open Graph Benchmark)

**基本信息**

| 项目 | 内容 |
|------|------|
| 来源 | Stanford SNAP \| NeurIPS 2020 |
| 地位 | 图机器学习领域最权威的Benchmark |
| 引用 | 2000+ 次学术引用 |

**数据集详情**

| 数据集 | 规模 | 节点特征 |
|--------|------|----------|
| ogbn-arxiv | 169K论文 | 128维文本向量(摘要) |
| ogbn-papers100M | 111M论文 | 128维文本向量(摘要) |
| ogbn-mag | 1.1M论文 | 128维文本向量(标题) |

**OGB的优势**
- ✅ 大规模、真实世界数据
- ✅ 标准化评估流程
- ✅ 广泛的学术认可
- ✅ 丰富的基线模型

**OGB的局限**
- ❌ 节点特征仅为128维文本向量（论文摘要的skip-gram编码）
- ❌ 无原始论文内容
- ❌ 无图像、无公式、无图表
- ❌ 丢失了论文的大部分语义信息

## 第5页：OGB vs 我们的工作

### OGB vs 我们的工作：详细对比

| 维度 | OGB | 我们的工作 |
|------|-----|-----------|
| 领域 | ✅ 学术论文 | ✅ 学术论文 |
| 数据规模 | ✅ 1.1亿论文 | ⚠️ 可扩展 |
| 文本特征 | 128维向量(仅摘要) | 完整Markdown文档(全文+公式) |
| 图像特征 | ❌ 无 | ✅ 论文图片 |
| 公式特征 | ❌ 无 | ✅ LaTeX公式 |
| 图表特征 | ❌ 无 | ✅ 表格+图表 |
| 多模态融合 | ❌ 单模态 | ✅ 多模态 |
| 原始数据 | ❌ 仅向量 | ✅ 原始文件 |
| 可解释性 | ⚠️ 低(向量难以解释) | ✅ 高(原始内容) |

**核心差异**

```
OGB:  论文 → 摘要 → 128维向量 → 图节点
我们:  论文PDF → 全文MD + 图片 + 公式 → 多模态图节点
```

**我们弥补的OGB空白**

> OGB告诉你: "这篇论文的摘要向量是[0.12, -0.34, ...]"
>
> 我们告诉你: "这篇论文有9张图片、97个公式、包含以下内容..."

## 第6页：对比对象二 - MAGB

### 对比对象二：MAGB (Multimodal Attributed Graph Benchmark)

**基本信息**

| 项目 | 内容 |
|------|------|
| 来源 | ACM Multimedia 2024 |
| 论文 | "When Graph meets Multimodal" |
| 地位 | 首个多模态属性图Benchmark |
| GitHub | https://github.com/sktsherlock/MAGB |

**MAGB的数据来源**

| 领域 | 数据内容 |
|------|----------|
| **社交网络** | Twitter: 用户节点 + 推文文本 + 头像图片<br>微博: 用户节点 + 博文文本 + 图片 |
| **电商平台** | Amazon: 商品节点 + 商品描述 + 商品图片<br>淘宝: 商品节点 + 商品文本 + 商品图 |
| **电影推荐** | IMDb: 电影节点 + 剧情简介 + 海报图片 |
| **新闻媒体** | 新闻: 文章节点 + 新闻正文 + 新闻配图 |

**MAGB的优势**
- ✅ 首个多模态属性图Benchmark
- ✅ 包含文本和视觉两种模态
- ✅ 提供标准化评估框架
- ✅ 评估了GNN和VLM两类方法

**MAGB的局限**
- ❌ 领域不匹配：社交/电商/电影，非学术领域
- ❌ 缺乏学术论文特有的公式属性
- ❌ 缺乏学术论文特有的图表（实验结果图、方法架构图）
- ❌ 引用关系缺失或不完整

### MAGB vs 我们的工作：详细对比

| 引用网络 | ❌ 无/不完整 | ✅ 完整引用关系 |
| 节点关系 | 社交关系/购买关系 | 引用/作者/主题关系 |

| 特殊内容 | 无 | 包含数学公式渲染、表格数据等专业内容 |

**我们弥补的MAGB空白**

> MAGB: 多模态属性图的"通用"解决方案
>
> 我们: 多模态属性图的"学术论文垂直"解决方案
>
> **额外提供的学术特有属性:**
> - 公式LaTeX源码
> - 实验结果图表
> - 引用关系网络

## 第8页：对比对象三 - 经典数据集

### 对比对象三：经典引用网络数据集

**Cora / CiteSeer / PubMed**

| 项目 | 内容 |
|------|------|
| 来源 | 机器学习早期基准数据集 |
| 用途 | 图神经网络节点分类的标准Benchmark |
| 历史 | 被引用超过10,000次 |

**数据集统计**

| 数据集 | 节点数 | 边数 | 类别数 | 特征维度 |
|--------|--------|------|--------|----------|
| Cora | 2,708 | 5,429 | 7 | 1,433 |
| CiteSeer | 3,327 | 4,732 | 6 | 3,703 |
| PubMed | 19,717 | 44,338 | 3 | 500 |

**经典数据集的优势**
- ✅ 历史悠久，广泛认可
- ✅ 规模适中，便于快速实验
- ✅ 大量现有工作可对比

**经典数据集的局限**
- ❌ 规模太小（最大仅2万节点）
- ❌ 特征为词袋/TF-IDF，语义信息有限
- ❌ 无原始论文内容
- ❌ 无图像、无公式、无图表
- ❌ 数据老旧（2000年代初期）
- ❌ 不适合评估现代大规模图模型

## 第11页：我们的核心优势

### 我们的四大核心优势

#### 1️⃣ 领域专注：学术论文垂直领域
- 区别于MAGB的通用领域
- 针对学术研究的特殊需求设计
- 包含学术特有的公式、图表、引用关系

#### 2️⃣ 多模态丰富：文本+图像+公式三位一体
- 区别于OGB的单一文本向量
- 区别于MAGB的文本+图像（无公式）
- 提供学术论文的完整语义信息

#### 3️⃣ 自动化采集：多Agent数据流水线
- 区别于所有现有数据集的人工/半自动采集
- 可复现、可扩展、可定制
- 降低数据构建成本

#### 4️⃣ 原始数据：保留完整论文内容
- 区别于OGB/经典数据集的特征向量
- 支持多种下游任务和模型
- 可解释性更强

## 第13页：研究动机总结

### 为什么需要这个工作？

#### 动机一：填补空白

| 现有数据集 | 局限 | 我们的工作 |
|-----------|------|-----------|
| 现有学术论文图数据集（OGB、Cora等） | 只有文本特征，丢失了论文的视觉信息 | ✅ |
| 现有多模态属性图数据集（MAGB等） | 来自社交/电商领域，无法反映学术研究特点 | ✅ |
| **我们的工作** | **学术论文领域的多模态属性图** | - |

#### 动机二：学术研究的特殊需求

学术论文包含独特的多模态内容：

| 内容类型 | 重要性 | 现有数据集 |
|---------|--------|-----------|
| **公式** | 表达核心方法和理论 | OGB和MAGB都没有 ❌ |
| **图表** | 展示实验结果和方法架构 | 社交/电商数据集没有 ❌ |
| **引用网络** | 学术知识传承的核心结构 | MAGB没有 ❌ |

#### 动机三：自动化需求

```
PDF论文 → 结构化多模态数据
```

这个过程需要自动化工具支持，我们提供了完整的多Agent采集系统。
