# 论文核心故事线（统一重构版，2026-06-20）

> 目标：2027 顶会（KDD/NeurIPS/ICML/WWW 候选）。
> **重构后一句话**：多智能体系统让我们**可控制地构建**多模态属性图(MAG)，把"图同质性"和"模态-标签纠缠"从构建副产物变成**可调旋钮**；据此建首个**构建可控**的 MAG 基准，证明下游"用哪个模态/用不用结构"由这两个构建可控属性决定，并揭示现有 LP 高分源于**构建期的标签捷径**、可被智能体抑制。

> ⚠️ **本版相对旧版的核心修正**：旧版把"多智能体建图"和"benchmark 发现"并列成两个独立卖点，逻辑断裂（reviewer 会问"为什么需要多智能体"）。重构后二者是一个**因果闭环**：构建决策=基准的两个轴（见 §1）。

## 1. 核心论点（统一版）

### 1.0 旧版的致命断裂（必须修，否则必拒）
旧版把"多智能体建图"和"模态×同质性 benchmark"并列成**两个独立卖点**，逻辑断裂：
- 多智能体系统 → reviewer 眼里 = 爬虫/ETL，换脚本也能做 → "为什么必须多智能体？"答不上。
- benchmark 发现(结构翻转/LP 虚高) → 普通 GNN 结论，和"多智能体"无因果 → A 不够 novel，B 不需要 A，逐个击破。

### 1.1 统一逻辑：构建决策 = 基准的两个轴（核心重构）
**基准刻画的两个轴，不是神秘的内禀属性，而是多智能体系统"怎么建图"的直接后果。**

| 基准轴 | 对应的"智能体构建决策" | 实证证据 |
|---|---|---|
| 图同质性 homophily | 智能体画什么边（同流派/同主演→同质；跨类型→异质） | tmdb 0.24 vs wikiart 0.89，差异源于关系定义 |
| 模态-标签纠缠 | 智能体编码什么为特征（类型描述→泄漏标签；剧情→不泄漏） | CLIP 文本读元数据→LP 捷径；虚高源于特征构建期 |

→ **双向闭环**：
- **(系统→基准)** 智能体是生成/操控这两个轴的**实验仪器**；没有可控构建就没有干净的 2 轴对照。
- **(基准→系统)** 基准发现 = **构建处方**：要 LP 好→智能体须避开标签泄漏的关系/特征；要 GNN 有用→构建同质关系。**LP 虚高是"构建期引入的病"，可由智能体关系/特征选择抑制。**

→ 两半成为**一件事**：智能体=旋钮，基准=测量，发现=处方依据。缺一不可。

### 1.2 让闭环"承重"的 3 个新实验（缺则闭环仍是嘴上说说）
- **E1 结构调控(steering)**〔最关键〕：同一域同节点同特征，智能体构建 N 种关系变体→不同同质性→下游**可预测**翻转。这一个实验把"智能体=旋钮"从口号变证明。
- **E2 构建质量/消融**：智能体 vs 规则基线建图、agent 组件消融。回答"为什么必须多智能体"。
- **E3 标签泄漏抑制**：改特征构建(类型描述→剧情/无标签字段)→LP 去饱和 gap 缩小。证明 LP 虚高是构建病、可治。

### 1.3 三条实证发现（成立，重新定位为"构建后果"）
（3 域同质性谱 tmdb 0.24 → steam 0.53 → wikiart 0.89，全跑通）

1. **结构增益随同质性翻转**（NC：GCN/GIN 异质 tmdb 崩 0.18–0.22 → 高同质 wikiart 升 0.90–0.97）。→ 重新定位：**"画什么边"(构建决策)决定 GNN 该不该用**。

2. **模态胜负取决于结构**（纯特征 text 赢；高同质加结构后弱图像被追平 wikiart GAT-img 0.968≈text 0.973）。→ 重新定位：**"编码什么为特征"与"画什么边"耦合决定模态胜负**。

3. **LP 被构建期标签捷径虚高**（wikiart random AUC 0.989≈被解出；去饱和后真实 0.84；Δ 随同质性×类数↑）。→ 重新定位：**这是构建病(特征/关系构建期标签泄漏)，不是模型强**。

**第四个 robust 反直觉卖点**：GIN 在 3 域 LP 去饱和后都最强（hard_deg 0.82/0.84/0.89）却在 NC 全域最差——sum 聚合保结构(LP)却过平滑特征(NC)，是"模型×任务×域"交互的活教材。

## 2. 与 3 个竞品的护城河

| 竞品 | 缺什么 | 我们的对应卖点 |
|---|---|---|
| MAGB (KDD'25) | 手工脚本建图；只报聚合数；无同质性分析；无去饱和 | ①多智能体自动建图 ②同质性×模态交互分析 ③LP 去饱和协议 |
| OpenMAG (ICML'26) | 规模大但多模态弱/文本为主 | 完整 text+image 双模态跨域 |
| MM-GRAPH (CVPR'25) | 视觉为主，域少 | 4 域跨同质性谱 |

护城河 = **一个统一闭环**（不是三件套）：多智能体构建是**仪器**（操控 2 轴），基准是**测量**（刻画构建后果），发现是**处方**（指导构建）。竞品的根本缺口：它们**手工建图→结构固定不可控→无法做"构建决策↔下游"的因果对照**，只能报聚合数。
- vs MAGB：手工脚本、结构不可控、无构建-性能因果分析、无去饱和揭穿。
- vs OpenMAG：多模态弱/文本为主，无构建视角。
- vs MM-GRAPH：域少、结构不可调。

→ **同质性↑ → 结构从有害→有益，单调穿越。** GCN/GIN 在异质图崩溃是亮点。

### ★ 跨域汇总表 2 — Q1：模态 × 结构交互（NC macro-F1）
```

tmdb      0.24   0.508   0.310   0.298    0.317    否(+0.007)
```

### ★ 跨域汇总表 3 — LP 去饱和（text+image；标签捷径严重度）
```
domain    homo   #cls   random  hard   hard_deg Δ(r-hd)  GIN-hd
tmdb      0.24   18     0.877   0.834  0.762    0.115    0.843
steam     0.53   7      0.889   0.862  0.807    0.083    0.821
wikiart   0.89   64     0.989   0.865  0.836    0.153    0.892
```
→ **wikiart random AUC 0.989 = 基准被标签捷径"解出"**；去饱和后真实 ~0.84。
捷径严重度随 **同质性 × 类数(基础率倒数)** ↑：tmdb(异质,18类) < steam(中,7类) < wikiart(同质,64类)。
GIN 三域 LP-hard_deg 都最强(0.821/0.843/0.892)却 NC 最差 → **模型×任务交互** robust 卖点。

### NC（acc / macro-F1）逐域
- **arxiv**(旧基线)：text 0.91 / image 0.81；所有 GNN≈MLP（旧基准疑似饱和，结构中性）。text 主导。
- **steam**(0.53 中)：mlp+text 0.68/0.53、graphsage 0.706/0.56、gcnii 0.714/0.56 最强；gcn/gat<mlp；gin 失败；text>image。
- **tmdb**(0.24 异质)：MLP+text 0.694/0.508 全场最强；GCN text 崩 0.219，GIN text+image 灾难 0.089；仅 GraphSAGE/GCNII 抗住。text>text+image>image。
- **wikiart**(0.89 同质)：**GNN 碾压**——GAT text 0.973/image 0.968/text+image 0.968；gcnii 0.940；graphsage 0.960；MLP+text 0.910；GIN 又最差 0.589。

### LP 去饱和（AUC: random/hard/hard_degree, text+image；Δ=random−hard_degree）
- **steam**(0.53)：mlp .889/.858/.801(Δ.088)、gcn .897/.871/.805(.092)、gat .852/.817/.771(.081)、graphsage .904/.880/.834(.070)、gin .903/.884/.821(.082)。均值 Δ≈0.083。
- **tmdb**(0.24 异质)✅：mlp .837/.791/.700(Δ.136)、gcn .893/.855/.778(.116)、gat .862/.808/.732(.129)、graphsage .885/.830/.757(.128)、gin .910/.887/.843(.067)。均值 Δ≈0.115。
- **wikiart**：待跑。

**⚠️ 重要修正（推翻原假设）**：desaturation **不随同质性单调上升**——异质 tmdb(0.115) > 中等 steam(0.083)。
机制修正：去饱和幅度主要由 **特征−标签纠缠度**（特征对标签的预测力）驱动，而非图同质性。
纯特征 MLP 在两个域都有 desaturation（特征相似度→标签→预测边的泄漏），幅度随特征对标签的判别力↑。
→ **更干净的 2-轴映射**：
  - **Q2 用不用结构** ↔ **同质性**（NC：GNN−MLP gap 随同质性从负→正穿越，已证 tmdb负/steam≈0）
  - **Q1 用哪个模态** ↔ **特征−标签纠缠**（LP desaturation 严重度 + NC 模态排行；多模态基准独有）
  → **反直觉卖点**：GIN 在 LP 最强(tmdb .910/steam .903)却在 NC 最差——sum 聚合保结构(LP)却过平滑特征(NC)。

## 6.5 ★ STEERING 实验结果（E1，统一闭环的承重梁，2026-06-20 ✅）

**设计**：同域同节点同特征同切分同初始化种子，**只换边**（按 `attributes.relation` 筛，外加 all=全图）。
代码：`benchmark/run_steering.py`(NC) / `run_steering_lp.py`(LP)，loader 加 `relation=` 参数。

### 6.5.1 NC steering —— 旗舰证据（干净、决定性）
MLP 三域跨关系**纹丝不动**(spread=0.0000，自检通过) → 证明所有 GNN 差异纯来自"画哪种边"。
GCN F1 随"构建决策驱动的同质性"单调翻转：

```
GCN text macro-F1  vs  关系同质性（所有关系变体撒在一条曲线上）
tmdb  shared_actor(.22).224  all(.24).219  shared_genre(.24).350  same_director(.33).332   ← 全低于 MLP(.504)，结构有害
steam shared_cat(.44).274  shared_genre(.44).467  all(.53).307  same_pub(.60).386  same_dev(.82).568  ← 穿越 MLP(.537)
wikiart same_artist(.88).866  all(.89).903  shared_style(1.0).956                              ← 远超 MLP(.909)
```
**GNN−MLP gap 随同质性从正(有害)→负(有益)穿越，零点≈0.5–0.6；steam 单域内(.44→.82)即完成穿越。**
→ 这把"多智能体=旋钮"从口号变证明：同一批数据，纯靠"画哪种边"就让 GCN 从 0.22 冲到 0.96。
→ wikiart shared_style(1.0) 时 GAT/graphsage 冲到 0.99(结构≈背标签)，构建退化的铁证。

### 6.5.2 LP steering —— 支持性证据（较弱，诚实记录）
同设计，GCN 在 random/hard/hard_degree 三档测去饱和：
```
steam:  all(.53) rand.897/Δ.061 | same_dev(.82) rand.990/Δ.028 | shared_genre(.44) rand.973/Δ.016
tmdb:   all(.24) rand.891/Δ.113 | shared_actor(.22) rand.924/Δ.090 | same_director(.33) rand.953/Δ.064
wikiart:all(.89) rand.993/Δ.100 | same_artist(.88) rand.997/Δ.048 | shared_style(1.0) rand.998/Δ.010
```
**诚实结论**：固定特征下 LP 主要由**特征−标签纠缠**主导，关系旋钮影响弱于 NC：
- 干净点①：wikiart **shared_style=1.0**(边即同标签) random AUC **0.998**——构建一个"标签恒等关系"的图，LP 直接被解出，**基准测不出东西**=构建退化铁证(用饱和度而非去饱和 gap 衡量)。
- 干净点②：random AUC 在 wikiart 全关系 0.99+(高纠缠域整体饱和)；去饱和后真实 ~0.89–0.95。
- 噪声：去饱和 Δ 在域内不随同质性单调(特征固定→特征信号恒定→LP 信号主要由特征而非结构决定)。
→ **LP 的"严重度随域变化"故事用跨域(§6 表3: steam.083<tmdb.115<wikiart.153)更干净；域内 steering 主要支撑"构建可造退化基准"这一点。**

### 6.5.3 对闭环的意义
- **NC steering 单独就足以承重"agent=旋钮"核心论点**（GNN/MLP 翻转、MLP 恒定对照）。
- LP steering 补强"构建决策可造退化/饱和基准"（wikiart shared_style→LP 0.998）。
- → 论文统一闭环**实验上成立**。E2(agent vs 规则基线)/E3(泄漏抑制)为可选加强，非必需。

## 7. 风险预案（reviewer 攻击点）

0. **"为什么必须多智能体？换脚本不行？"**（最致命，统一版核心防御）→
   多智能体不是"爬得快"，而是**唯一能把图结构当可调旋钮**的范式：手工脚本的边是硬编码规则、结构固定不可控，做不了"构建决策↔下游"的因果对照(E1)。Agent 把关系推断/模态选择显式化→结构可观测可调→才能闭环。E1+E2 实证支撑。
1. **"homophily 影响 GNN 早有研究"** → 反驳：在**多模态+构建可控**图上首次；模态×结构产生新失效；LP 去饱和+构建病视角全新。
2. **"arxiv 和新域 pipeline 不同不可比"** → 统一 text+image 子集做可比对照；arxiv 仅作锚点。
3. **"4 域不够铺满 2 轴"** → E1 结构调控在同一域内连续移动同质性轴，比加域更可控；辅以 arxiv 子域。
4. **"CLIP 编码引入偏差"** → 统一编码器正是为了隔离模态/结构效应；E3 改特征构建验证泄漏机制。

## 8. 待补实验（统一闭环优先）

### 8.1 闭环承重实验（最高优先级——让 agent↔benchmark 不再是嘴上闭环）
- [x] **E1 结构调控 steering**〔最关键，已跑通 2026-06-20，见 §6.5〕：边已带 `attributes.relation` 类型，
      同域内单类关系同质性跨很大区间（实测，= agent"画哪种边"的旋钮）：
      ```
      steam:  shared_category .440 / shared_genre .437 / same_publisher .595 / same_developer .817
      wikiart: same_artist .876 / shared_style 1.000  ← style=标签，构建期标签捷径铁证
      tmdb:   shared_actor .217 / shared_genre .240 / same_director .329
      ```
      做法：同域同节点同特征，按关系筛边建 N 个子图 → 各自重跑 NC+LP → 验证
      "构建决策→同质性→GNN/MLP 翻转 + 去饱和变化"因果。**steam 单域 .44→.82 即跨 0.38，足以成旗舰图。**
      **这是把多智能体从'爬虫'升级为'旋钮'的决定性实验。**
