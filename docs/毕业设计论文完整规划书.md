**AMMAG 填补的是三类工作的交汇空白**：
- 比 OGB/CS-TAG **多了多模态属性**（图像+公式+表格）
- 比 DocGenome/M3SciQA **多了图结构**（引用网络连接多篇论文）
- 比 MAGB/OpenMAG/MM-GRAPH **多了学术领域和公式模态**

### 第一章 绪论（~5页）

#### 1.1 研究背景与意义（~2页）

**写法**：从三个角度切入，层层递进

**第一段——图神经网络与Benchmark的发展**：
- 图神经网络（GNN）在社交网络、推荐系统、药物发现等领域取得巨大成功
- Benchmark 数据集是推动图机器学习发展的关键基础设施
- OGB（NeurIPS 2020）提供了标准化评估框架，极大地促进了图学习研究
- 然而，OGB 等现有图 Benchmark 的节点属性多为低维文本向量（如 ogbn-arxiv 的128维 skip-gram 向量），**丢失了原始文本和视觉信息**

**第二段——多模态属性图的兴起**：
- 多模态属性图（Multimodal Attributed Graph, MAG）同时包含图结构和多模态节点属性
- MAGB（KDD 2025）首次系统定义 MAG 学习范式，覆盖5个电商/社交数据集
- OpenMAG（arXiv 2026）扩展至19个数据集，MM-GRAPH（CVPR 2025）引入更全面的多模态图评估
- **但这些工作均限于文本+图像双模态，且未覆盖学术论文领域**

**第三段——学术文献的特殊价值与现有空白**：
- 学术论文天然是多模态属性图：节点=论文，边=引用，属性=全文+图表+公式+表格
- 学术论文的多模态具有独特性：**公式是学术论文特有的模态**，MAGB/OpenMAG/MM-GRAPH均未包含
- 现有学术图基准（OGB、CS-TAG）仅提供低维文本向量
- 现有多模态学术基准（DocGenome、M3SciQA）仅关注单文档理解，无图结构
- **本文工作**：构建首个面向学术论文领域的多模态属性图 Benchmark AMMAG

#### 1.2 国内外研究现状（~1.5页）

**分类综述，用一张表总结**：

| 类别 | 代表工作 | 核心贡献 | 关键局限 |
|------|---------|---------|---------|
| 单模态学术图 | OGB, CS-TAG, CITE, TEG-DB | 大规模图+标准化评估 | 仅文本属性，无图像/公式 |
| 多模态学术文档 | DocGenome, M3SciQA, MCiteBench | 多模态文档理解 | 无图结构，单文档视角 |
| 通用多模态属性图 | MAGB, OpenMAG, MM-GRAPH | MAG学习范式 | 非学术领域，无公式模态 |
| 自动化构建 | GROBID, AutoData | 数据采集自动化 | 非学术MAG设计 |

**关键结论**：学术界缺乏一个同时具备"学术论文领域 + 多模态属性（含公式） + 引用网络 + 自动化构建"的 Benchmark。

#### 1.3 本文贡献（~0.5页）

列出 4 点贡献（每点2-3句话），**强调与现有工作的差异**：

1. **首个学术多模态属性图 Benchmark 数据集 AMMAG**：覆盖 CS/Math/Physics 三个学科大类，包含文本、图像、公式三种模态属性和引用网络结构。与 MAGB/OpenMAG 相比，AMMAG 首次纳入公式模态；与 OGB/CS-TAG 相比，AMMAG 提供原始多模态属性而非低维向量。

2. **基于多智能体协同的自动化构建系统**：设计五智能体流水线（下载→提取→清洗→图构建→格式化），实现从 arXiv 元数据到标准化 MAG 数据集的端到端自动化。与 GROBID 等半自动工具相比，本系统支持多模态提取和引用图自动构建。

3. **全面的 Benchmark 实验**：在节点分类、链接预测、模态消融、Few-shot、跨领域迁移等任务上系统评估 5 种 GNN 模型 × 7 种模态组合，为学术 MAG 学习提供基线结果。

4. **模态消融分析与学术领域特性发现**：首次在学术图数据集上量化分析文本、图像、公式三种模态的贡献差异，发现 text+formula 组合优于纯文本，而三模态简单拼接存在模态失衡问题，为未来学术 MAG 融合策略提供实证依据。

#### 2.2 多模态属性图基准（~2页）

**这是最核心的相关工作节，要详细写三个工作**：

**MAGB（KDD 2025）**：
- 5个数据集覆盖电商（Amazon Movies/Toys/Grocery）和社交（Reddit）
- 文本+图像双模态，16个基线模型
- 关键发现：社交网络偏好视觉特征，电商偏好文本特征；简单拼接存在模态不平衡
- **局限**：不含学术领域，不含公式模态，不含引用网络

**OpenMAG（arXiv 2026）**：
- 19个数据集，6个领域，8个评估任务
- 模型覆盖更广（16个编码器+24个基线模型），评估维度更多
- **局限**：同样不含学术领域和公式模态

**MM-GRAPH（CVPR 2025）**：
- 5个多模态图数据集，支持模态消融实验（G/T/V/GT/GV/TV/GTV）
- **局限**：仍为文本+视觉双模态，无学术领域，无公式

**引出本文工作**：MAGB、OpenMAG、MM-GRAPH 三大多模态属性图基准均不包含公式模态，且未覆盖学术论文领域。AMMAG 首次将公式模态引入 MAG 基准，填补学术领域的空白。

#### 2.3 多模态学术文档理解（~1.5页）

- M3SciQA（EMNLP 2024）：多文档多模态科学QA，含图表/公式
  - **与AMMAG的关系**：QA导向无图结构，AMMAG 关注图学习任务
- MCiteBench（EMNLP 2025）：多模态引用生成
  - **与AMMAG的关系**：引用生成 vs 引用网络构建
- SciFIBench（NeurIPS 2024）：科学图表理解
  - **与AMMAG的关系**：单图表理解 vs 图中节点的图表属性

**关键对比**：这些工作关注单文档/多文档的多模态理解，但均未将论文构建为图结构进行图学习任务。

### 第五章 Benchmark 实验与分析（~10页）← 最重点章

#### 5.1 实验设置（~1.5页）

**5.1.1 特征编码器**：

| 模态 | 编码器 | 输出维度 | 说明 |
|------|--------|---------|------|
| 文本 | Sentence-BERT (all-MiniLM-L6-v2) | 384 | 长文档分段编码+均值池化 |
| 图像 | CLIP ViT-Base-Patch32 | 512 | 多图编码+均值池化 |
| 公式 | Sentence-BERT（LaTeX当文本编码） | 384 | 公式提取+编码+均值池化 |
| 多模态融合 | 简单拼接(Concat) | 1280 | 384+512+384 |

**5.1.2 基线模型**：

| 模型 | 说明 |
|------|------|
| MLP | 无图结构baseline，仅用节点特征 |
| GCN | 图卷积网络 (Kipf & Welling, ICLR 2017) |
| GAT | 图注意力网络 (Veličković et al., ICLR 2018) |
| GraphSAGE | 采样聚合 (Hamilton et al., NeurIPS 2017) |
| GIN | 图同构网络 (Xu et al., ICLR 2019) |

**5.1.3 超参数与评估设置**：

| 参数 | 值 |
|------|---|
| 隐藏维度 | 256 |
| GNN层数 | 2 |
| Dropout | 0.5 |
| 学习率 | 0.01 |
| 优化器 | Adam |
| 训练轮数 | 500 (early stopping patience=50) |
| 重复次数 | 5次（不同随机种子） |
| 评估指标 | Accuracy, Macro-F1, MRR, Hits@K |

**5.1.4 标签说明**：
- 使用 arXiv 交叉类别作为子分类标签（5类）
- cs.SI纯(8274)、cs.LG(1707)、cs.CL(802)、cs.CY(778)、cs.AI(368)

#### 5.2 节点分类实验（~2页）

**实验目的**：验证多模态属性在学术论文分类任务上的有效性

**结果表格**（对标 MAGB Table 2）：

| 模型 | Text | Image | Formula | Text+Image | Text+Formula | Text+Image+Formula |
|------|------|-------|---------|-----------|-------------|-------------------|
| MLP | 78.13 | - | - | - | - | - |
| GCN | 77.40 | 72.70 | 69.88 | 76.23 | **77.49** | 76.12 |
| GAT | 77.81 | - | - | - | - | - |
| GraphSAGE | 78.17 | 72.49 | 70.41 | 76.50 | **78.17** | 76.09 |

> （标注"-"的需补充实验数据）

**分析要点**：
1. **文本是最强模态**：text-only (78.17%) 远超 image-only (72.49%) 和 formula-only (69.88%)
2. **公式有一定增益**：text+formula (78.17%) 与 text-only 持平或略好
3. **简单拼接存在模态失衡**：三模态拼接反而下降，与 MAGB 的发现一致
4. **GNN vs MLP**：GraphSAGE (78.17%) ≈ MLP (78.13%)，说明引用图结构在当前设置下增益有限（平均度仅0.75）

#### 5.3 模态消融实验（~2.5页）← 论文核心创新

**实验目的**：量化每个模态的边际贡献，**这是 AMMAG 区别于 MAGB/OpenMAG 的核心实验**

> **创新点说明**：MAGB、OpenMAG、MM-GRAPH 均只包含文本+图像双模态，AMMAG 首次引入公式模态，使得消融实验能够量化公式在学术图任务中的独特价值。这是现有 MAG 基准无法开展的实验。

**消融表格**：

| 配置 | GCN Acc | GCN F1 | Δ vs Text-only | GraphSAGE Acc | GraphSAGE F1 |
|------|---------|--------|---------------|---------------|-------------|
| Text-only | 77.40 | 47.03 | baseline | 78.17 | 47.60 |
| +Image | 76.23 | 42.07 | -1.17 (↓) | 76.50 | 41.83 |
| +Formula | 77.49 | 45.16 | +0.09 (↑) | 78.17 | 47.40 |
| +Image+Formula | 76.12 | 41.71 | -1.28 (↓) | 76.09 | 41.50 |

**可视化**：画一张柱状图，横轴是模态组合，纵轴是 Accuracy 和 F1

**分析要点**：
1. **公式模态的独特价值**：text+formula 是唯一比纯文本更好或持平的组合，印证了公式在学术论文分类中的语义补充作用
2. **图像模态的挑战**：科学图表（架构图、实验结果图）比电商/社交图片复杂得多，CLIP通用视觉编码器可能不适合科学图表（与MAGB发现社交图偏视觉的结论形成对比）
3. **多模态融合策略的重要性**：简单拼接不够，需要领域适配的融合方法——这为未来工作提供了方向
4. **与 MAGB 的异同**：MAGB 发现电商偏好文本、社交偏好图像；AMMAG 发现学术领域偏好文本+公式，图像反而引入噪声

#### 5.4 Few-shot 学习实验（~1页）

**实验设置**：3-shot 和 10-shot，5次重复

**预期结果表格**（待实验）：

| 模型 | 模态 | 3-shot Acc | 10-shot Acc | Full Acc |
|------|------|-----------|------------|---------|
| GCN | text | - | - | 77.40 |
| GCN | text+formula | - | - | 77.49 |
| GraphSAGE | text | - | - | 78.17 |

**分析要点**（参考MAGB发现）：
- Few-shot 场景下多模态是否仍有增益？
- MAGB 发现 3-shot 时模态偏差会降低性能，AMMAG 是否也有此现象？

#### 5.6 跨领域迁移实验（~1页）

**实验目的**：验证模型在不同学术领域间的泛化能力

**实验设计**（需等 cs.LO 数据完成）：

- 反之亦然

#### 5.7 可视化分析（~1页）

**t-SNE 可视化**：
- 对 text / image / formula / text+image+formula 四种 embedding 做 t-SNE 降维
- 按子类别着色（5种颜色）
- 展示不同模态的聚类效果差异

#### 5.8 结果讨论（~1页）

**总结关键发现**：

1. **公式模态在学术MAG中的独特价值**：text+formula 是最优组合，这是 AMMAG 独有的发现，MAGB/OpenMAG 因缺少公式模态无法得出此结论
2. **学术图片的特异性**：科学图表与电商/社交图片差异大，通用视觉编码器效果不佳，呼应了 DocGenome 对科学图表理解挑战的讨论
3. **多模态融合在学术图上的双刃剑效应**：简单拼接引入噪声，需要领域适配的融合策略
4. **引用图结构的价值**：在低平均度（0.75）的稀疏图上，GNN 增益有限，但链接预测任务中图结构是核心

5. 图像编码器（CLIP）不适合科学图表 → 训练领域适配的视觉编码器
